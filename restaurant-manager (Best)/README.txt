========================================
  RESTAURANT MANAGER - Setup Guide
========================================

Thank you for downloading Restaurant Manager!
This app helps you manage your restaurant:
- Dashboard with sales charts
- Products & Menu management
- Storage & Inventory tracking
- Sales & Point of Sale (POS)
- Purchase orders
- Workers & Staff

Your data is saved in a file called "database.db"
(it is created automatically when you first run the app)


STEP 1: INSTALL PYTHON
----------------------
You need Python installed on your computer.

1. Go to https://python.org/downloads
2. Download Python 3.10 or newer
3. Run the installer
4. IMPORTANT: Check the box "Add Python to PATH"
5. Click "Install Now"

To check if Python is installed, open your terminal/command prompt
and type: python --version


STEP 2: START THE APP
---------------------

WINDOWS:
  Double-click the file named "start.bat"
  OR open Command Prompt, navigate to this folder, and type:
    start.bat

MAC / LINUX:
  Open Terminal, navigate to this folder, and type:
    ./start.sh
  OR:
    bash start.sh


STEP 3: OPEN IN BROWSER
-----------------------
Once the app is running, open your web browser and go to:
  http://127.0.0.1:5000

The app will open and you can start using it!


WHAT EACH SECTION DOES:
----------------------
- DASHBOARD: See today's sales, low stock alerts, and charts
- SALES: Create new orders by clicking products (like a cash register)
- PRODUCTS: Add/edit your menu items and prices
- STORAGE: View and update inventory levels
- PURCHASES: Track orders from suppliers
- WORKERS: Manage your staff list


STOPPING THE APP:
-----------------
Press CTRL+C in the terminal window where the app is running.


NEED HELP?
----------
If you see any errors, make sure:
1. Python is installed correctly
2. You are in the correct folder
3. You have internet for the first run (to download the chart library)

Your data is automatically saved - nothing will be lost when you close the app!
